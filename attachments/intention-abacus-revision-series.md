# Intention Abacus — revision series after the 8-lens review

**Date:** 2026-09-16
**Status:** Proposal. Not an implementation grant until Paul says begin.
**Purpose of the instrument:** make an ongoing discussion and its trajectory visible. When an explicit shared goal exists, the table either walks toward a living pattern or names “not a fit.” The picture never authorizes Yes.

Favorite visual lock remains `intention-abacus.html`: ice/paper, Fraunces + IBM Plex Mono, torus table, platonic center, hoop beads, gold only after a human command.

---

## What stays

Walk: Self (individual Yes on a goal) → orbit while roles are discussed → Tribe (Agree roles → N-gon on the horizontal plane) → World (how / spokes / lenses) → Transcendent (human Commit → inside→outside the torus → outer-equator orbit).

Also stays: spinning torus + Hopf field, hourglass cones, four seats (Maya / Finn / Bea / Sam or live names), reveal-only holarchy panel, Ready ≠ Yes, proposed ≠ authority, fiber ≠ routing.

`Commit` remains a human button. Conflict never greys it. Conflict must be visible before it.

## Series (screenshot-testable ships)

### R0 — Discipline copy
Stamp every phase caption: “This picture is evidence. It is not a Yes.”
Gold tetra / outer equator only after human Commit, never when chamber count ticks or a distance drops.
Rename UI that says “aligned” → “revealed” / “stable” / “in tension.”
Calculator drops Chern / holonomy-as-badge. Keep numbers that mean something on this table: version, confirmed records, readiness, clarity, risk, live contradiction count.
Header subtitle can stay “Beads, not people, move.”

### R1 — Trajectory ribbon
Each seat leaves a fading trail on the table plane. Color = seat. Opacity dies like α = 0.82 per turn (visual echo of CDISS decay, not a grant).
Thickness = |Δbase| that turn. Off-plane wobble = |Δfiber| (mood orbit).
If the action signature flips while the trail is short (ε = 0.06, window 4): ribbon kinks, caption “the pointer is ringing — ask, don’t act.” Auto-lerp freezes one beat. No gold.
This is the missing time axis. Ongoing discussion becomes a smear that either closes into a period or does not.

### R2 — Per-seat, per-level state
Stop painting one holarchy onto four colors.
Each seat holds four 8-corners (Self, Tribe, World, Transcendent).
Nested shells stay one picture. ViewLevel chip lights that shell’s corners and dims the others.
Holarchy panel: per-seat four-point alignment first, group second. Never an average that erases a No.

### R3 — Name the eight corners
Cube-vertex labels on the selected shell. Same eight names for the session.
Default set unless the table names its own (open question below):

1. purpose
2. scope
3. timing
4. resources
5. risk
6. care
7. authority
8. completion

Alignment at a corner = that seat leans toward that vertex. Conflict at a corner = two seats pull it opposite ways (split tick, not a merged average).
If axes stay unnamed, caption must say “coordinates are unlabeled; distance is heuristic.”

### R4 — Proposed vs Confirmed
Dashed thin spoke = proposed. Solid spoke = confirmed / active.
Only solid spokes count toward the chamber calendar.
Permission-kind confirmed = full opacity. Other confirmed kinds = 0.25 opacity (matches the engine).
Confirmed spoke grows a pearl. Pearls persist. Beads remain the field. Proposed never thickens the platonic fill.
Memory may tint a bead. Memory cannot lengthen a spoke or raise task-readiness glow.

### R5 — Cross-level and vow-vs-vow reveal
Draw C(level_i, level_j) = (base distance, fiber distance, agreement support) as a thin ink hairline between shells plus one caption line: “Maya’s Self yes fights her Tribe role on [axis].”
Two confirmed pearls that contradict: both stay; a crossed mark between them. Chamber count does not fill the next solid while that mark is live.
Commit stays clickable. Formation does not auto-advance.

### R6 — Fiber vs base motion
Fiber (emotion, posture, urgency): bead may bob on its local hoop / off-plane. Cannot snap the polygon, cannot grow spokes, cannot step outside the torus.
Base (intent, topic, readiness, risk): only this moves polygon vertices, spoke length, and the inside→outside step.
Visual test: crank mood on a seat — hoop swirls, square stays. Caption: “weather is moving; the plan is not.”
Do not call this a computed Hopf map.

### R7 — Strength before clip
Bead radius / halo = magnitude before L2 clip.
Position on the hoop = heading after clip.
Without this the table mistakes direction for commitment.

### R8 — Not-a-fit (first-class formation)
New terminal phase, sibling to polyhedron, not a failed Commit.
Trigger: human button “This is not a fit,” or a witnessed pause that leaves a goal without Commit. Never a conflict score.
Choreography: N-gon opens (one vertex steps off the circle); spokes withdraw from the hole; lenses fold; beads drift apart on the table plane; hourglass dims; outer equator never populates; gold never hits the solid.
Caption: “the table named a miss, not a failure.” Ice + one broken brass edge. No red prison.
Ledger a NotFit record the same way Commit is ledgered. Fresh attempt returns to orbit around the same or a new goal.

### R9 — Chamber as calendar
Ghost outline of the next solid when confirmed_count crosses 6 / 8 / 12.
Filled solid steps only if no live contradiction mark.
If marks exist: counter may read 8; solid stays Surface/wire; caption “the count rose; the vows do not commute.”
Star-tetra appears only when four vertices are seated and commute-gate is clean — two ways of seeing four points, not a prize for eight signatures.
Icosahedron never authorizes the outer-equator step.

### R10 — Goal as optional generator
No goal: field + fiber weather + trajectory only.
Goal + k people who Yes: generate the chosen platonic and k points. People who have not Yes’d stay off the polygon.
Agree-roles with 3 of 4 draws three sides and a gap, not a perfect square with one dim bead.
Census does not draw the lodge.

### R11 — Oscillation freeze
Reuse the engine rule visually. Formation pose flip + short trails → freeze lerp one beat, “ask again,” no gold, tools stay human.

### R12 — Language purge
Must not say: quantum coherence, Hilbert, entanglement, “Hopf proves,” “the icosahedron means we agree,” “CDISS approved,” “aligned.”
May say: fiber weather, base station, confirmed record, reveal, not a fit, trajectory, in tension, stable pointer.
