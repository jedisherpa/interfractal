# Gate 11 first browser acquisition transport review

**Verdict: incomplete CUA object transport, with no Gate 11 app defect established by these hash failures.** The preserved candidate 002 acquisition has 101 DOM observations. Independently recomputing the hashes from the stored parsed objects succeeds for 79 semantic payloads and 35 information payloads. Of the 22 semantic failures, 21 contain literal `[MaxDepth]` replacement text inside the captured semantic payload. All 66 information failures contain that replacement inside the captured information payload. These are truncated acquisitions; they must not be counted as successfully rehashed or silently reconstructed.

The remaining semantic failure is observation 94, `manual-replay`. Its captured active cursor is `0.16290000009536745`. Holding every other captured semantic field fixed and lowering only that IEEE-754 double by one ULP to `0.16290000009536743` yields the published fingerprint exactly. This proves the stored CUA object changed that numeric value in transport. It does not prove every app frame is correct. Four string-valued local/tour exports checked here contain no `[MaxDepth]`, but those exports cannot substitute for each full DOM snapshot.

The independent reproduction is `diagnose-candidate-002-transport.mjs`; its machine result is `candidate-002-transport-diagnosis.json`. The host verifier at `/tmp/g11-host-verify.mjs` also reported the initial failure counts but is not used as the independent oracle. Preserve the first acquisition and gather complete `JSON.stringify` observations as strings into a separate directory, then independently hash the complete second acquisition before core closure. No implementation change or candidate 003 is indicated by the transport evidence alone. This review makes no claim about human outcomes or the still pending complete browser audit.
