The presentation is then stranded with `phase=running`, `presentationPaused=false`, and no timer. 2. **Practice reinspection during a local presentation is still labeled standard playback.** [`practice`](../../matched-observation/engine.mjs) pauses the saved tour but does not pause an exploration watch/static clock. The watch and static running rows show zero local stop calls, `presentationPaused=false`, and `reviewStatus=standard-playback` after `practice-open`. The shared practice card is additional teaching available during the timed route, so this is a manual access deviation from the frozen uninterrupted-forward convention. Pause the local clock and mark `manual-review` on opening practice during a running local presentation, or disable the practice control until that presentation ends. Keep the card and logging behavior common across modes.
3. **A same-hash completed route can display a stale export with wrong provenance.** [`render`](../../matched-observation/app.mjs) clears a prior route export only when phase, condition, or trace hash changes. Both states are `choose/complete` with the same deterministic trace hash, so the clear predicate is false while the export still says `local_control` and the selected trace now says `scripted_demonstration`. The current export button must still produce the new route's actual envelope.
