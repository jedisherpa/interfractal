# Gate 12 coordination instrument

This public four-context software instrument records two explicitly referenced local rankings and a separate stipulated joint procedure. It does not enact an export, contact groups or infer consent. `model.mjs` derives exact proposal and outcome content from the frozen fixture; `app.mjs` keeps immutable local branch records, a separate scripted registry, same-information diagram/plain views and a 24-second tour.

Build and test with `/opt/homebrew/Cellar/node@24/24.17.0/bin/node`. The immutable server binds only to 127.0.0.1 and requires explicit `--run`. Review assets are absent until the host stages exact hash-approved files under `coordination/review/` and lists them in `review/allowlist.json`. Local branch records are in memory; export them before reload. Export is available in saved-tour mode too, to capture its actual event prefix with an empty local branch list.
