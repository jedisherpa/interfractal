# Gate 7 — unfamiliar cases and a bounded conclusion

Version `gate7-prespec-v1`. Approved scope is the actual user message **“Approve Gate 7: Unfamiliar-case interpretation and the bounded conclusion.”** The host records that authority separately. Historical approval language is preserved unchanged.

This final gate prepares a participant-facing instrument and checks it computationally and through actual browser operation. **No human study is executed, no participant answer is invented, and no human participation is a completion prerequisite.** An agent exposed to the source, answer key or predictions performs software/model validation, even when it clicks the task controls. A later request by Paul to try the tasks is a separate actual participation event, not something this gate approval silently supplies.

## Frozen question and scope

Can eight unfamiliar, precisely bounded tasks expose both recoverable properties and genuine insufficiency, keep explanations withheld until deliberately requested, and faithfully present the same finite task information in contrasting layouts? Their content spans selected 4D points, single-source-view ambiguity, hidden versus exposed fifth coordinates, projection versus slice, ambiguous slice settings, compact summaries, and a changed receiving requirement over expanded fictional records.

The task set is intentionally small and synthetic. It is not a validated comprehension scale. Source point identities are local to each case; Q03 and Q04 use different source points. Record prior exposure if anyone later tries them. Do not interpret a tour as an unfamiliar-case test. No alternate forms are claimed to be matched or validated.

The files frozen before the builder's browser trials are:

- `task-fixture.json`: the only task-facing data, including prompts, neutral IDs/options, declared facts, exact observations and reference/record data.
- `private-answer-key.json`: private scoring choices, explanations and derivations; never a public asset.
- `independent-predictions.json`: pre-implementation closed-form expectations, ranks, witnesses, invariants and replay checkpoints; private audit material, not task UI data.
- This charter, `model-contract.md`, and `record-contract.md`.

The host writes a separate `PRESPEC_FREEZE.json` with these six hashes after independent review. Do not mutate frozen files to fit observations. Preserve a failure and state the deviation; at most two justified implementation revisions follow the initial candidate. Material changes of model, task, scoring or information require a versioned specification and explicit review, not an unnoticed implementation fix.

## Observation conditions and equal access

For each geometry task, static shows all three supplied frames simultaneously; prescribed presents the same three frames in order, each held for two seconds, with discrete transitions and no interpolation; interactive permits choosing only those three frames in any order. All show the same captions, formulas, point correspondences, raw xyz tables and display scale. No condition gets hidden source coordinates, scoring, extra source angles, arbitrary transforms or computed ranks. Static layout may make images smaller; report actual image sizes and any illegibility.

Their underlying observation set is equal, but their access is different: static supports simultaneous comparison, prescribed requires temporal comparison, and interactive permits revisiting a chosen frame. Pausing/replaying/manual stepping are available and must be logged. These are not equal cognitive burdens or equal measured exposure by assumption. No advantage follows from information equality alone. If any condition accidentally receives more information, mark the comparison unequal and exclude any advantage claim.

The shared teaching card contains only the four statements in the public fixture; recommended teaching time is 60 seconds, then 45 seconds per task. These are proposed limits for a later optional session, not enforced timers or measurements of an unrun session. Unlimited pause/manual operation remains available for accessibility and review. Any eventual extra teaching, repeated exposure or elapsed time must be recorded, not silently treated as matched.

Q07 and Q08 each support local-object and plain-table rendering of exactly the same supplied facts, references, receiving rule and frame choices. Q07 has only one summary frame and no undisclosed cost records in its task data. Q08 has three reference/requirement frames and its unchanged complete cost records. The two tasks use different fictional contexts so Q08 does not disclose Q07's missing values. Geometry, central placement and links add no new decision rule. Do not render a computed receiver answer or mapped yes/no result that supplies the requested answer before reveal. Raw records, formulas and available facts remain visible.

## Optional later order and response plan

No orders are assigned to people in this gate. A future small exploratory session can use one of three geometric condition rotations across Q01–Q06: S/P/I/S/P/I, P/I/S/P/I/S, or I/S/P/I/S/P. Cross these with graph→plain or plain→graph attention order. Rotate or reverse the six geometry case order separately, recording the plan. Each participant sees a base case once before explanation; repeating it in another mode is a practice-contaminated observation, not a fresh matched trial. These rotations are a prospective counterbalancing aid, not a sampled randomized design or evidence of balance. Withhold explanations until the planned first-exposure set is complete when comparing cases; earlier explanations can teach a solution method and contaminate later performance even though source identities differ.

Each task offers explicit answer submission or **Skip answering**. Both create a locked, unscored receipt. **Reveal explanation** is a second intentional action, available only after that receipt. A skip records no choice and never becomes a wrong answer. Export, if used, identifies software validation separately from unattributed local interaction; browser clicks cannot authenticate a human participant. Fresh reload and Reopen saved clear transient answers and explanations. No explanations are preloaded in DOM, JavaScript, source maps, task APIs or public static files.

## Pass, fail and interpretation

Readiness requires correct public data and model arithmetic; valid insufficiency witnesses; source/camera separation; exact information identity across representations; key isolation before deliberate reveal; response/skip/reveal/reset behavior; paused repeatable replay; and actual browser observations and inspected originals. An independent audit must examine exact frozen build bytes as well as evidence. A functional failure or unresolved leakage prevents an unqualified readiness result. A readable screenshot does not prove a user understands it.

Report five separate rows in the final synthesis: mathematical checks and assumptions; properties identified within the declared model and remaining ambiguity; actual human observations (**not tested** in this gate); interface evidence including clutter/controls/plain comparison; strongest counterexample and next smallest experiment. Do not compute a human comprehension percentage from source-informed agent checks. Software option submissions are mechanics tests, not participant scores.

The expected strongest limitation is observational non-uniqueness: camera changes cannot restore information omitted by a fixed projection; equal slice radii do not identify signed settings; omitted dependencies defeat compact summaries. The preserved Gate 4 3D-movie counterexample also prevents claiming that appearance proves a higher-dimensional cause. Which interface best supports unfamiliar interpretation remains open.

The proposed smallest next experiment is one separately requested, recorded think-aloud session on unrevealed cases, with a fixed first-exposure plan, plain comparison and no population claim. A further matched-form study would need separately designed cases and participant authorization. New object families, formal bundles, VR, public deployment and the four-agent shared-meaning study are outside this gate. Stop with the final replay collection and a recommendation; do not execute that next scope.
