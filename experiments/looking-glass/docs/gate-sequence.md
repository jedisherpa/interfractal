## Definitions that later gates must preserve

- Full coordinates define genuine 4D/5D models; animation time remains a separate variable. Use column-vector rotations, explicit plane controls, and documented composition order.
- Source rotation, source-to-3D projection, ordinary display-camera motion, and playback time are independently controlled and recorded. A moving 3D mesh alone is not a 4D model.
- A source hypercube's solid dimension, boundary, drawn wireframe, and affine span are different descriptions. Eight aspects, twelve lenses, participant counts, observations, and geometric coordinates are not interchangeable counts.
- `S³` has intrinsic dimension three and can be embedded in `R⁴`. The Hopf map `S³→S²` and stereographic representation `S³→R³` serve distinct roles. Finite rendered samples do not constitute drawing every fiber.
- A geographic base point, sphere center, and semantic shared reference remain distinct. Any later `M_r(record)` is a declared model with reference ID/wording/scope/author/version/criteria, stable records, ambiguity, and a plain view. Loop position is a display choice unless circular structure is justified.
- Typed links among local models form a graph unless stronger bundle structure is actually specified and verified. Organizational scale is not a new spatial dimension. Geometric linking does not prove social influence, agreement, or authority.
- Numerical recovery from known transforms and stable point correspondences does not prove reconstruction from arbitrary screenshots or uniquely identify a higher-dimensional physical cause.

## Packet and boundary at every gate

Each packet contains an actual paused historical replay with run/build identity; a short watch guide; two to four inspected original screenshots including decisive failures; question/expected/observed/interpretation/unresolved table; changes and preserved failed runs; and the next named stage's concrete scope. If blocked, disclose the actual failed path and last successful replay instead of fabricating a result.

Finish or stop current-stage workers, freeze the packet, and ask for Paul's decision. Then end the turn. No worker performs later-stage research or implementation while approval is pending. Opening a replay is read-only evidence review. Only the actual user message or a supported trusted human action can authorize the next named gate; automation never approves for Paul.

If Paul requests a revision, remain in the current gate, version the changed definition/build/run, and return an updated packet. Material changes to hypotheses, scoring, or model scope require another review. A negative, mixed, inconclusive, or blocked finding can be an honest gate outcome; no positive conclusion is required.
