# Independent Gate 1 audit — G1-CUBE-003

**Qualified instrument result.** The frozen ordinary-cube build `g1-9dce1c2b9c2b3be4` agrees with the prespecified 3D source, x–z rotation, 2D shadow, and fixed display camera. Root's actual browser trial exercised the controls, saved 26 inspector observations and seven indexed screenshots, and reproduced the same checkpoints after Run Library reopen and page reload. One recording-contract requirement is unmet: the in-app `playback.pause` event at the automatic 40-second stop does not say whether the pause was automatic or manual. The external browser control trace and observed states substantiate this trial's auto-stop, but the raw in-app log cannot establish the event's origin by itself. This limitation does not change the cube/shadow calculation; it prevents an unqualified event-schema pass.

The auditor did **not** implement the calibration or operate the browser. This report checks independently derived arithmetic, the exact immutable snapshot, local read-only routes, root's recorded DOM inspector states and activity log, original capture files, and frozen bytes. A software and investigator-visual result is not evidence that a person understood an unfamiliar higher-dimensional object.

## Preservation, deviations, and limits

The first candidate, [G1-CUBE-001](G1-CUBE-001-build-audit.json), failed before browser use: a camera-yaw typo produced `NaN` camera coordinates, serialized as `null`. Its build and run remain preserved. [G1-CUBE-002](G1-CUBE-002-build-audit.json) passed numerical and snapshot checks but was replaced before browser testing so the historical Gate 0 build label and free preview port were explicit. G1-CUBE-003 is the only browser-tested Gate 1 candidate. Port 43993 was occupied by an unrelated existing Python server, so root documented the local transport deviation to 43994 without changing the model or prespec.

Two initial audit-tool failures are also preserved: [route audit initial](G1-CUBE-003-route-audit-initial.json) queried `/api/current-run` on Gate 0, whose actual endpoint is `/api/run`; [browser audit initial](G1-CUBE-003-browser-audit-initial.json) incorrectly required the inspector's seventh screenshot to appear in the observation record rather than its separate capture index. Both were auditor-checker errors, corrected transparently; final checks pass. Neither describes an application defect.

The automatic pause origin is a real [recording-contract deviation](G1-CUBE-003-browser-audit.json), not a failing rotation or UI-control observation. The external browser trace covers this one execution, but future replay logs should distinguish automatic completion from a manual Pause without relying on an external operator record. This gate establishes a bounded, known-source instrument calibration. It does not establish arbitrary 2D-to-3D reconstruction, unfamiliar-object comprehension, Hopf behavior, 4D/5D geometry, or the archived human shared-meaning experiment. Gate 2 has not been approved.
