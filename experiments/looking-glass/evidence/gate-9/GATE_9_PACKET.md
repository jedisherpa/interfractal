## Evidence and qualifications

The accepted closed core contains **307 complete DOM observations, 135 recorded action calls (134 successful and one disabled export), 13 original JPEGs, 12 primary endpoint exports and four labeled regression exports**. Three browser sessions contain 132, 18 and 1 semantic events, totaling 151. Historical outbound/back navigation is documented separately from the main action-call count. The final browser collection restores the canonical paused start.

The disabled export was a host assumption error: a query after checkpoint 2 opened a fresh local draft with only one accepted choice. The control correctly refused export; its failed action and surrounding records were retained. The host supplied the second actual choice and preserved that trace. A distinct canonical checkpoint 2-resume regression was paused and manually finished after its sampling window; it is not the uninterrupted 24-second tour. See [collection notes](COLLECTION_NOTES.json), [event audit](../../audit/gate-9/event-audit.json), and [browser audit](../../audit/gate-9/browser-audit.json).

All 24 paused checkpoints and all 16 completed-route exports verify independently. At live observations 219, 236 and 283, both Python and JavaScript canonical rehashes disagree with the adjacent captured fingerprint. Each snapshot had an active fractional tour clock. The code's asynchronous hashing and live rendering are consistent with a non-atomic snapshot, but the alternate state is absent, so the exact mechanism remains unproven. The [live fingerprint review](../../audit/gate-9/live-fingerprint-review.json) retains both hashes. Those three snapshots cannot establish a self-consistent live state/fingerprint pair; the other 304 do. No core record was rewritten to repair the mismatch.

The 1280×720 and 960×720 layouts were inspected. Every original's dimensions match its observed CSS viewport; the third static card wraps and requires vertical scrolling at 960 pixels. The page reports no horizontal overflow. Early partial choice/watch viewport captures remain unchanged, with later full-card captures added. Seven default-width observations were 1279 pixels wide, including the final reset to the original viewport. Console review recorded no errors. No OS reduced-motion setting, human gaze, attention or perceived exposure was tested.

The frozen common practice and fixed two-selection rule are the same across modes. Choose remains untimed; watch holds each occurrence for two nominal seconds, and the static review timer lasts six seconds. Pausing keeps content visible. Fixed recipe order and choose→watch→static access are source-informed software checks, not balanced independent human exposures. Exact information parity does not match timing, agency, memory demand, repeated inspection or pixels.
