# Gate 3 hypercube instrument

This isolated local instrument implements the approved four-coordinate hypercube and a moving orthographic 3D projection. It draws the projected wireframe in SVG through a separate ordinary camera. The full solid is `[-1,1]^4`; the 32 drawn edges are its one-dimensional skeleton. The interface does not implement slices, 5D, a human study or public deployment.

The planned canonical run is `G3-TESSERACT-001`, 32 seconds, with checkpoints at 0/8/16/24/32 seconds. The source x–w angle is 0°/45°/90°/45°/0°; the camera stays yaw 30°, pitch 20°. `v1110` and `v1111` remain distinct source IDs. Their w-edge `e-v1110-v1111` is retained even when its projected length is zero. An SVG site hit containing two IDs discloses both IDs; the Vertex and Edge selectors resolve exact identity. There is no positional jitter.

The fixed and camera-only observability cases remain rank three with hidden-w nullspace. The known source 0°+90° case has rank four. The solver in `model.mjs` accepts only opaque matched IDs, supplied 3×4 projection matrices and raw observed 3D coordinates. It does not decode an ID or read the source fixture. A separate evaluator compares its result to source truth afterward. The inspector includes all 16 point results and their maximum coordinate error and maximum absolute forward residual. These are numerical checks under declared controls, not screenshot reconstruction or human comprehension evidence.
