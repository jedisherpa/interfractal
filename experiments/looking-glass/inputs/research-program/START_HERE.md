# Collective Capability Across Scales — research package

Prepared for Paul Cooper, 20 September 2026. Design v0.3 carries forward the shared-meaning question and proposed four-snapshot bench. The baseline v0.2 received independent AI challenge review; these additions have not. This is a research-design and instrument-development handoff, not a report of human findings.

## Central question

Under what conditions, if any, can an interactive visual model help participants build, test, and revise shared meaning across perspectives and scales, improving coordination while preserving consequential differences and participant agency?

The original collective-capability question remains the broader program question.

The visualizer is one instrument for investigating this question. Its practical value must be tested separately from whether collective capability and useful cross-scale interfaces exist. Four participants are an initial fixture choice; eight aspects and twelve lenses remain revisable design vocabularies. No Fibonacci ratio, ideal polyhedron, universal flatness limit or social-dimensional ladder is presumed.

## What the first build should do

For the new language branch, prepare and check the small synthetic evidence corpus, snapshot schema, input manifest, and withheld transfer key described in the amendment. This preparation can inform the evidence-instrument slice below; it does not replace the existing lantern calibration or establish visualizer efficacy.

Start with one versioned evidence record and a useful plain workspace. Add relationship and temporal views, then a compact group offer that exposes dependencies, limits, mandate and source detail. Test identical underlying records across the plain and visual conditions. Keep model interpretations separate from human attestations. Existing hash-derived feeling/conflict graphics are synthetic display rules and cannot serve as psychological measurements.

The two research paths share faithful records and suitable measures. One tests the practical effect of offering visual views. The other studies capability, interaction and group interfaces, using the plain workspace if that is sufficient. Synthetic cases can begin early; human studies need their actual instrument, measurement, consent/review and inference plans. A null graphics result must not stop the broader inquiry.

## Reproduce the delivered bench

From this directory, using Python 3 with the standard library:

```sh
python3 studies/verify_fixture.py
```

The checker writes `studies/synthetic_check_result.json`. It checks 32 specified lantern plan-state combinations, three distinct observations for four proposals, and four world/request combinations for exclusive battery resources. The latter shows how equal two-kit offers can conceal different simultaneous delivery capabilities. These are bounded synthetic checks. They do not test the B/C applications, human understanding, interaction advantage or predictive dynamics.

[First-session materials](studies/FIRST_SESSION_MATERIALS.md) distinguish investigator-only keys, fictional characters, planned erroneous suggestions and actual system defects. They still require a frozen human delivery contract before administration.

## Source and interpretation limits

The original source drafts and operating context guided the brief. Current user corrections take precedence over older fixed-number proposals. Files labeled `UNATTESTED` in `evidence/` are historical proposal material, not current findings. The user-source manifest identifies original attachments; the originals and some temporary text extractions are not redistributed in this archive. Paths mentioned in frozen reviews may refer to those original working inputs. Repository snapshots and their manifest are included.

The full text of *Surfaces and Essences* was unavailable. The cognition analysis uses accessible author material and related original research, with access limits disclosed; it does not claim to have read the whole book. Source-level software inspection is not a deployed-runtime audit. No application changes, participant recruitment, human pilot, study registration or efficacy results are included.

The external deadline is unspecified. Relative work estimates are assumptions, not promises. The immediate completed outcome is a reviewed design package ready to guide instrument development; each subsequent claim has its own evidence gate.
