## Decisions across independent R1 proposals

| Decision | Disposition and reason |
|---|---|
| Full protocol × geometry factorial | Deferred. First efficacy comparison is the practical offer of visualizer C over the capable plain workspace B. This identifies the immediate incremental question with fewer arms; protocol effects remain a separate study. |
| Guided case comparison | Retained as a separate learning/transfer intervention. Do not bundle it with rendering and then attribute the effect to geometry. |
| Correction-channel manipulation | Retained as a later mechanism study. Basic correction/access rights remain available in every initial condition. |
| Fixed aspects/lenses/group counts | Eight/twelve remain candidate vocabularies. Four is the initial fixture size for tractability and code compatibility; 3/5 nearby and 12 stress cases, not a ceiling. Self-authored contributions initially isolate the visualizer question. |
| Geometry/Hopf construction | Retained as an optional mathematical/teaching laboratory with explicit mappings. Not used as a measurement of mind, capability or authority. |
| Agent-created endorsement | Rejected as human attestation. Model attribution and human exact-target endorsement are distinct records. |
| Immediate live LLM | Deferred until provenance and correction work with reproducible synthetic traces. |
| Capability primary | Retained for later efficacy trial; comprehension/feasibility comes first during instrument development. Mixed calibration probes are not a capability/coherence composite. |
| Cross-scale inquiry | Preserved as an independently advancing research path using a plain interface if appropriate; a positive visualizer result is not a prerequisite. |

## Release condition

The design package can be released when the targeted R3 reports find no unresolved contradiction blocking its stated instrument-development purpose and package integrity checks pass. That release is not permission to claim human effectiveness, a completed application, external expert endorsement, or a registered study. Later prerequisites remain in the protocol and execution plan.
