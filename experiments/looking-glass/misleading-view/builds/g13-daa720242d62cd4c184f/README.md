# Gate 13 misleading-view instrument

This public fictional software demonstration compares three authored count statements. A local check and correction are immutable source-bound records with explicit software provenance. The bar view and plain table share exact source counts, axis values, widths, checking controls and information hashes. No human belief, persuasion or learning is measured.

Use `/opt/homebrew/Cellar/node@24/24.17.0/bin/node`. The immutable server binds only to loopback and requires an explicit absolute `--run` directory. Local records are in document memory: export before reload; reload creates a new document UUID. The saved tour has separate scripted records and does not turn them into local checks.

Review assets are served only after the host stages hash-approved files under `misleading-view/review/` and lists exact routes in `review/allowlist.json`.
