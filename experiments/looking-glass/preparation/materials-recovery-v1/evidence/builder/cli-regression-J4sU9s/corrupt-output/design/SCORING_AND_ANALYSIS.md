# Scoring and analysis proposal — no collected outcomes

The author key is a finite derivation from stipulated sources and rules. An independent reviewer must derive from the five frozen source/task/schema files without reading it, freeze that derivation, then compare. Record and resolve disagreements before future collection. Shared engineering filesystem access means procedural blindness only. Source correctness, software validation and human comprehension remain separate claims.

## Exact atoms and scope

D01–D08 contain 38 value atoms per scope: 2 demand, 3 capacities, 5 P12 distinctions, 5 P10 distinctions, 4 attribution/mandate distinctions, 1 inspection, 15 plan components and 3 selection fields. D09/D10 add four full-union atoms. Score initial A1–A4 against their own six-card key, never against an unseen union. Union and interactive final artifacts use the 42-atom union key. The key also provides canonical evidence traces; these are illustrative complete proofs, not a requirement to cite irrelevant facts.

Each value atom earns 1 iff its JSON value exactly matches the scoped key (including null, ordered IDs and four distinct statuses); otherwise 0. Missing/malformed/budget-truncated atoms earn 0 and retain a separate reason. Report numerator/denominator and error type, not a single unqualified accuracy score. Separate exact provenance score: 1 iff every cited source exists in the delivered scope, no superseded/model-only source is treated as current actor evidence, and the cited facts plus rules suffice for the asserted value; otherwise 0. A shorter valid proof earns the same provenance credit. Unknown requires a named missing dependency and no invented negative evidence. For a supported numeric claim, the selected current quantity and its supersession rule must agree with all supplied evidence. Valid references alone are insufficient.

Mechanical semantic scoring uses the frozen atom map. Provenance/argument-role explanations require independent review against the explicit rule/fact trace; log reviewer disagreements rather than presenting them as automatic exact matches. Scores for source validity and substantive sufficiency are separate. A readable paragraph cannot rescue an incorrect machine value retrospectively; a justified ambiguity in materials triggers a preserved materials revision, not selective rescoring.

## Outcomes kept separate

1. **Source/record fidelity:** six-card coverage, IDs/versions, correction/restatement linkage, four-status distinctions and invalid/invented references.
2. **Understanding versus stance/commitment:** D03/D04/D05; preserve the understood-but-rejected commitment and the model-attribution boundary. Do not infer private understanding from a solver's score.
3. **Consequential distinction recovery:** D09/D10, source correction and retained disagreement; report deletion of a valid negative or conflict even when final choice happens to be correct.
4. **Development capability:** D07 component statuses and D08 selection/output/cost. This is task-local classification/proposal, not an enacted physical outcome.
5. **Transfer:** W01–W05 each have eight atoms (40 total). W06 has two contexts × (four bundles × seven fields + one selection)=58 atoms. Thus 98 transfer value atoms. Enumerate the empty bundle; do not treat a capacity duplication as independent capacity. Report W01/W02 relation contrast, W03 version boundary, W04 changed demand, W05 conflict, and W06 shared dependency separately.
6. **Cost/access:** actual tokens, reasoning-token accounting when available, all attempts, context bytes, retrieval, elapsed and total solver time. Never treat repeated anchors as four independent evidence sources.

No subjective confidence bonus. Wrong supported-ready choices, false mandates, lost dissent, stale grants and model-attributed endorsements promoted to actor truth are flagged individually even if total scores are high. No arbitrary single “coherence” index or weighted composite substitutes for these outcomes.

## Deterministic simple pooling

Keep every initial snapshot and its scope. Align each D01–D08 atom by task/atom name, retaining `(value, source scope, evidence, parent snapshot)` tuples; collapse only identical tuple copies. For a deliberately simple scalar readout, discard unknown/null/none_supported values only from the *candidate value set*, never from the retained tuples. If exactly one distinct remaining value exists, use it; if none exists, retain the unique missing marker appropriate to the atom; if more than one exists, mark `pool_conflict` (a pooling state, not a fabricated source truth). Do not resolve demand-version conflicts or recompute readiness from combined facts. This is an implementable naive comparator, not an oracle. The full pool remains available to its transfer evaluator.

Score the pooled D01–D08 readout against the 38 corresponding union atoms; `pool_conflict` earns zero unless the expected literal value is that marker (none here). Report D09/D10 as not elicited for pooling, not as covertly answered. Initial-scope accuracy and union-scope pooling accuracy answer different questions. Do not count a pooled missing marker as proof that no eligible action exists. Preserve conflicting local versions instead of a majority vote.

## Comparison and inference

The proposed budgets are intentionally unequal: pool reuses four initial calls; union sees all raw facts immediately; interactive receives broader evidence at exchange plus extra generation and synthesis. Report these differences beside every contrast. An improvement from initial to revised answers may be fully explained by newly available sources. Pool versus union differences may reflect omissions in snapshots. Neither identifies interaction benefit, visual benefit or human learning. The transfer evaluator adds identical maximum generation per branch but does not equalize prior work.

The proposed future twelve quartets use three explicit cyclic allocation rotations and four fresh-context replicates each. The exact maps/order are in execution-plan.json. Each quartet assigns all blocks once; using only three of four rotations does not fully balance each agent across all blocks. Reconfirm and freeze before collection. Analyze the replicate/quartet as the unit; snapshots, cards, atoms and anchor copies are not independent experimental units. Show all paired score vectors and costs, medians/ranges and exact counts; no superiority hypothesis test or population claim is justified by the small diagnostic proposal. Same-model training induces further dependence. A future resource-matched causal comparison needs a separate design and authorization.

Failures, malformed outputs, missing responses, transport retries and accidental exposure remain in the inventory. No replacement after inspecting scores. Expose exact denominator changes, if a whole context cannot be evaluated, and report worst-case missing-as-wrong alongside any descriptive complete-case view. Retain raw outputs and parser versions. No current four-agent, transfer, human or visual efficacy observations exist; these are preparation specifications.
